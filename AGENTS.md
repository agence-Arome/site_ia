# Conventions du projet

- Thème : présentation uniquement. Extension : données, formulaires, SEO et métier.
- Gutenberg natif ; ne pas modifier le cœur WordPress.
- Respecter WordPress Coding Standards, capacités, nonces, validation et échappement contextuel.
- Ne pas exposer les leads dans REST, recherche, flux, sitemap ou HTML public.
- Pas de secrets, données personnelles, sauvegardes ou dépendances générées dans Git.
- Ne jamais inventer témoignages, résultats, certifications ou coordonnées commerciales.
- Tester les parcours affectés ; documenter les limites de vérification.
- Aucun déploiement en production sans autorisation explicite.
