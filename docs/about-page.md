# Page Qui sommes-nous

Page /qui-sommes-nous/, éditable dans Gutenberg, accessible dans le menu et le pied de page. Sur une installation existante, mettre à jour le thème puis exécuter tools/seed-content.php avec WP-CLI : les pages existantes sont conservées. Régénérer ensuite tools/export-offline.cjs.

La page Notre approche est retirée. Pour une installation existante, exécuter tools/remove-approach.php avec WP-CLI après mise à jour du thème : mise en corbeille et remplacement des liens vers Qui sommes-nous, sans écraser les autres modifications de contenu.
