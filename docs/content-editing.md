# Modifier les contenus

## Pages et design

Ouvrir **Pages**, choisir le contenu puis modifier les blocs Gutenberg. La page d’accueil utilise des groupes, colonnes, titres, boutons et détails natifs. La composition illustrée « W. » est un élément décoratif HTML/CSS, sans information essentielle ; elle peut être remplacée ou supprimée.

Dans **Apparence → Éditeur → Styles**, ajuster la palette et la typographie. L’en-tête et le pied de page sont des parties de modèle. Le titre du site se change dans les réglages généraux. La navigation initiale est stockée dans le thème ; l’éditeur peut créer une version personnalisée en base.

Les personnalisations des modèles sauvegardées dans l’éditeur prennent priorité sur les fichiers du thème. Après une mise à jour, contrôler les modèles modifiés ; exporter les changements approuvés si leur versionnement est nécessaire. Ne pas réinitialiser ces personnalisations sans sauvegarde.

## Formulaires

Insérer le bloc **Demande de devis**. Dans son menu, choisir devis ou contact simple. Les champs et les validations restent gérés par l’extension ; ils ne sont pas des fragments HTML libres. Une seule instance par page est prévue.

Le devis affiche une question de qualification selon la prestation. Les URL `?service=creation`, `refonte`, `depannage`, `securite`, `maintenance` et `developpement` présélectionnent le service. Une valeur inconnue n’est pas acceptée par le serveur.

Conserver une page publiée `/merci/` avec le bloc **Confirmation de demande**. Ne pas y placer un texte statique affirmant qu’une demande a été reçue : le bloc le confirme uniquement après enregistrement.

## SEO, articles et réalisations

Le panneau **SEO essentiel** contient le titre facultatif et la description. Les articles disposent de compositions réutilisables, ainsi que les FAQ et les études de cas. Publier uniquement des contenus relus et utiles.

Les réalisations sont un type de contenu séparé qui survit à un changement de thème. La page `/realisations/` en affiche la liste. Ne pas publier les indications de rédaction comme si elles décrivaient un vrai projet.

## Informations à fournir

Nom commercial, identité légale, contact, hébergeur, politique de conservation et éventuels crédits graphiques. Compléter puis publier les pages légales, et sélectionner la politique de confidentialité dans **Réglages → Confidentialité**.
